# iPadOS 学习复盘面板 Trae 能力测试题

说明：本题组是用于测试 Trae 综合能力的模拟需求，不代表 Personal English AI 的真实产品需求。题目可以定义模拟 API 契约和 mock 数据，但不得要求实现真实后端、修改真实后端接口，或把该能力写成正式产品路线。

目标：在 iPadOS SwiftUI 客户端中实现一个学习复盘面板。题组分为 A 组和 B 组，每组 5 道题，共 10 道。A 组完成核心复盘体验，B 组增加复杂状态、数据一致性、边界处理、测试和文档回归。A 组和 B 组整体难度都偏大。

---

## A1：学习复盘总览页

标签：困难 / feature迭代 / 前端

### Prompt

请为 iPadOS SwiftUI 客户端实现一个学习复盘总览页。这个需求是能力测试题，不是真实产品需求；页面使用模拟数据或模拟 API 契约即可，不要接真实后端，也不要修改真实后端接口。

总览页需要让学习者在打开首页时快速看到近期学习状态，包括连续学习、学习时长、练习完成情况、AI 使用情况和综合学习评分。

### 要求

- 展示学习 streak、本周学习时长、完成练习数、AI 对话数、写作练习数、综合学习评分。
- 指标需要有清晰的标题、数值、单位和简短说明。
- 综合学习评分需要有视觉强调，能区分高、中、低三档状态。
- 页面需要兼容 iPad 横屏和竖屏，卡片不能在窄宽度下挤压重叠。
- 数据可以来自 mock service 或等价模拟数据层，但 UI 不应直接写死所有展示数据。
- 当数据为空时展示可理解的空状态，而不是显示 0 堆满页面。
- 该页面不得要求用户登录真实账号或访问真实服务。

### 验收标准

- 首页能看到完整学习复盘总览区域。
- streak、学习时长、练习数、AI 对话数、写作练习数、综合评分均可见。
- 高、中、低评分展示有明确视觉差异。
- iPad 横屏和竖屏下内容不重叠、不截断关键文字。
- mock 数据切换为空数据后，总览区域展示空状态。
- 构建通过，不影响现有登录、助手、写作和个人中心入口。

- loading 状态、空状态、错误状态都能被触发并正确显示。
- 错误状态点击重试后可以恢复到正常活动列表。
- 每条活动能看出类型、标题、摘要、时间和来源。
- 长列表滚动流畅，页面布局不跳动。
- 构建通过，现有 Dashboard 其他区域不回退。

能力画像需要展示学习者在语法、词汇、连贯性、写作、口语等维度的当前水平，并能看到近期变化趋势。

- 展示至少 5 个能力维度：语法、词汇、连贯性、写作、口语。

### 验收标准

- 5 个能力维度均可见，并展示当前分数和变化趋势。
- 上升、下降、持平三类趋势有明确视觉差异。
- 缺失值展示为“数据不足”或等价文案。
- 异常分数不会导致图形溢出、崩溃或显示超出范围。
- VoiceOver 能读出能力名称、分数和趋势。
- 构建通过，不引入第三方图表库。

## A5：复盘摘要生成

标签：困难 / feature迭代 / 前端

### Prompt（完成）

请为 iPadOS SwiftUI 客户端实现学习复盘摘要生成。这个需求是能力测试题，不是真实产品需求；摘要基于页面已有模拟数据本地生成，不调用真实 AI 服务，不接真实后端。

复盘摘要需要用中文概括学习者近期表现，包括亮点、短板和下一步建议。

### 要求

- 根据总览指标、最近活动、能力画像和目标进度生成中文摘要。
- 摘要至少包含三段：学习亮点、需要关注、下一步建议。
- 摘要内容需要随模拟数据变化而变化，不能永远显示固定文本。
- 当数据不足时，摘要需要说明数据不足，并给出开始学习的建议。
- 摘要生成需要有加载或生成中的状态反馈。
- 摘要区域需要支持复制文本。
- 不调用真实 AI 服务，不发送用户数据到网络。

### 验收标准

- 正常数据下可以生成包含亮点、短板和建议的中文摘要。
- 数据不足时生成数据不足版本的摘要。
- 修改 mock 指标后，摘要内容随之变化。
- 生成中状态可见，完成后状态恢复。
- 复制摘要后能获得完整摘要文本。
- 构建通过，网络断开时摘要仍可生成。

## B1：时间范围切换

学习者需要在今日、近 7 天、近 30 天之间切换，并看到整个复盘面板同步刷新。

### 要求

- 支持今日、近 7 天、近 30 天三个时间范围。
- 切换时间范围后，总览指标、活动流、能力趋势、目标进度和复盘摘要都需要同步更新。
- 当前选中的时间范围需要有明确视觉状态。
- 切换过程中需要显示局部 loading 或整体刷新状态。

- 每个时间范围都需要有不同的模拟数据，不能只是标签变化。
- 时间范围切换不得触发真实网络请求。

### 验收标准

- 今日、近 7 天、近 30 天三个选项均可点击或选择。
- 选择不同范围后，至少 4 个复盘模块的数据发生合理变化。
- 快速切换多次后，最终页面与最后选择的范围一致。
- 切换过程不会出现旧范围标题和新范围数据混杂的状态。
- 当前范围视觉状态清晰。
- 构建通过，现有模块不回退。

学习者需要按活动类型筛选最近学习记录，并按日期分组查看。

- 清除筛选或切回全部后，活动列表恢复。

## B3：异常数据与降级体验

标签：困难 / 工程化 / 前端

### Prompt（完成）

请为 iPadOS SwiftUI 客户端的学习复盘面板补齐异常数据与降级体验。这个需求是能力测试题，不是真实产品需求；异常场景通过模拟数据或模拟 API 契约触发，不接真实后端。

页面需要在数据缺失、数值异常、部分模块失败或整体加载失败时保持可用，不能因为单个模块失败导致整个复盘页面不可用。

### 要求

- 处理缺失字段、空数组、负数、超出上限分数、无效日期、未知活动类型。
- 单个模块加载失败时，只让该模块显示错误状态，其他模块继续展示可用数据。
- 整体加载失败时展示整页错误状态和重试入口。
- 未知活动类型需要使用通用图标和兜底文案。
- 无效日期需要显示兜底时间文案，不能崩溃。
- 异常数据不能污染复盘摘要，例如负数练习数不能被总结成真实完成量。
- 需要提供一种开发或测试可触发异常状态的方式。

### 验收标准

- 缺失字段不会导致页面崩溃。
- 负数和超出范围分数会被限制或显示为异常状态。
- 单个模块失败时，其他模块仍能正常展示。
- 整体失败时，点击重试可以恢复正常 mock 数据。
- 未知活动类型显示兜底样式。
- 构建通过，并有测试或可重复验证方式覆盖异常场景。
