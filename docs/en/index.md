## Documentation Purpose

This docs site is the project memory for the iPadOS client. It should stay practical and lightweight, and it should support development rather than replace it.

## Documentation Roles

- `AGENTS.md`: Long-term agent rules and project boundaries.
- `docs/roadmap.md`: Product and engineering roadmap.
- `docs/phase-log.md`: Completed work, open questions, and next steps.
- `docs/architecture.md`: App structure and major architecture decisions.
- `docs/ipados-development-plan.md`: Detailed planning reference.
