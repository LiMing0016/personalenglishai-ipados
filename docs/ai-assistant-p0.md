# AI 助手 P0 稳定闭环

本文档定义 AI 助手进入下一阶段前必须先完成的 P0 稳定性工作。P0 的目标不是增加更多展示能力，而是让登录、进入主界面、发送消息、停止生成、错误恢复和 iPad 横竖屏体验足够稳定。

## 为什么先做 P0

当前 AI 助手已经具备对话、流式输出、附件、文件夹、置顶、归档、分享、Markdown、Mermaid 和 D3 图形渲染等基础能力。但是在继续扩展学习路径图、能力树、作文结构图之前，需要先解决几个会反复影响验收的问题：

- 登录验证码通过后必须稳定进入正式页面。
- AI 后端不可用、模型不可用、登录过期时，前端需要给出清晰状态。
- 发送中、停止生成、重试和重新生成不能互相打架。
- iPad 横屏、竖屏、分屏下文字、气泡和输入框不能变形或不可点击。
- 用户要知道问题发生在本地输入、登录态、网络、后端还是模型侧。

## P0 验收目标

P0 完成后，应该可以按下面流程验收：

1. 使用已验证邮箱账号登录。
2. 完成滑动验证码后进入主界面，不再停留在验证码弹层。
3. 进入 AI 助手，新建对话并发送一条普通文本消息。
4. 回复生成过程中可以停止，停止后输入框恢复可用。
5. 后端关闭或模型异常时，页面显示明确错误，并允许重试。
6. 横屏和竖屏下，消息内容、输入框、顶部工具栏不被拉伸或遮挡。
7. 切换会话、归档、置顶、分享等基础操作不破坏当前聊天状态。
8. `xcodebuild` 测试通过。

## P0 范围

### 1. 登录进入主界面稳定性

- 验证码失败只刷新验证码，不误认为登录失败。
- 验证码成功后提交登录，登录失败不重新打开验证码弹窗。
- 登录成功但没有 token 时显示明确错误。
- 401 或 token 刷新失败时清理登录态并回到登录页。

### 2. AI 后端状态可见

- `load`、发送、流式输出、附件上传的错误要转成用户能理解的中文。
- 区分后端不可达、模型服务异常、登录过期、附件失败和普通请求失败。
- AI 助手页面应有轻量状态提示，避免用户只看到“AI 助手暂时不可用”。

### 3. 发送状态一致性

- 同一时间只允许一个生成任务。
- 快速连续点击发送不能制造多个 `assistant-loading` 占位消息。
- 流式成功但后续刷新对话失败时，不应该把已经生成的回答误标成失败。
- 停止生成后输入框必须恢复可用，当前回答标记为已停止。
- 失败消息保留重试入口，重试成功后清理失败状态。

### 4. iPad 本地交互体验

- 输入框整个区域可点击，并支持多行输入。
- 横屏和竖屏下用户气泡不超过合理宽度。
- 代码、长英文、长中文不会把聊天布局撑坏。
- 输入区使用安全区域，避免被系统边缘或键盘遮挡。

### 5. P0 测试覆盖

- 登录验证码状态机测试。
- 发送中重复提交测试。
- 停止生成状态测试。
- 流式成功但详情刷新失败测试。
- 后端错误消息映射测试。
- 附件校验测试。

## 不属于 P0 的内容

这些内容重要，但不放进 P0 第一批：

- 后端真实取消 run 的接口。
- 动态模型列表接口。
- 图形渲染的产品级视觉升级。
- 学习路径图、能力树、语法树、时间线等完整模板库。
- 写作、词汇、学习复盘等跨模块沉淀。

## P0 第一批执行顺序

第一批从最容易反复出问题的状态一致性开始：

1. 文档：记录 P0 范围、验收方式和非目标。
2. 测试：先补发送状态和流式边界测试。
3. Store：收紧 `AssistantStore` 的并发发送、停止和失败状态。
4. UI：修复输入框可点击范围、横屏气泡宽度和错误提示。
5. 验证：运行 `xcodebuild` 测试并在 Simulator 手动检查一次。

现有执行计划见 `docs/superpowers/plans/2026-06-20-ai-assistant-p0-p1.md`。该计划覆盖无需新增后端接口的第一批 P0/P1 工作，后续如接入动态模型列表或真实取消 run，需要和后端联调文档同步。

## 2026-06-22 第一批落地内容

本轮先完成不依赖后端新增接口的 P0 闭环：

- `AssistantStore` 增加可恢复状态提示，区分后端不可达、模型异常、登录过期、同步失败和普通请求失败。
- 流式回答成功但详情刷新失败时，保留已经生成的回答，并显示同步失败提示。
- 模型失败时保留重试草稿，用户可直接从错误提示或消息操作里重试。
- 停止生成会取消当前流式任务，将占位回答标记为“已停止”，并恢复输入状态。
- 聊天页增加顶部轻量状态提示条，不再只依赖全局弹窗。
- 输入框扩大可点击区域，横屏下用户气泡增加最大宽度约束，避免文字和代码块横向拉伸。
- 补充 `AssistantStoreTests` 覆盖后端不可达、模型失败、停止生成、刷新失败保留回答、重复发送和横屏气泡宽度。
